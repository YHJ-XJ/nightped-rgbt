# LLVIP TCC 首轮留出实验

2026-11-27 完成。三个组都用 YOLO26n RGB＋热红外四通道、S3′ 均值初始化、种子 42、训练 10 轮，并取末轮 EMA 权重。训练排除前缀 25 后剩 10,013 对。项目验证集有 1,589 对，前缀 25 探针有 423 对、845 个框。

| 末轮指标 | P0 无增强 | P1 整图热退化 | P2 带符号局部热编辑 |
| --- | ---: | ---: | ---: |
| 项目验证集总体 mAP50–95 | 54.97% | 53.88% | 53.09% |
| 前缀 25 总体 mAP50–95 | 56.58% | 58.72% | 57.66% |
| 前缀 25 负＋近零对比度 AP50–95（422 框） | 50.94% | 53.36% | 50.73% |
| 前缀 25 负对比度 AP75（274 框） | 40.44% | 51.28% | 36.76% |

总体指标来自 Ultralytics，子组指标来自同一套 COCO 式分层评估。P2 未通过首轮筛选，前缀 25 的负＋近零组 AP50–95 比 P0 低 0.22 个百分点，比 P1 低 2.64 个百分点。P1 在前缀 25 的负对比度组 AP75 提高 10.84 个百分点，在项目验证集的负对比度组 AP75 由 35.25% 降至 30.70%。本轮证据来自一个种子和一个留出探针。[筛选结果](analysis/screening.json) · [完整分层指标](analysis/stratified_ap.csv)。

单卡 RTX 4090 上训练调用合计 31 分 42 秒，另有双集评估和分层汇总。三组模型均为 2,534,030 参数、6.057 GFLOPs（640 输入，未融合训练图）。每份权重为 5,443,333 字节，SHA256 和原始路径记录在各组 `tcc_result.json`。
